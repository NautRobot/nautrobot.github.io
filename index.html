Improving the Game with Logic (Conditionals)

I used conditional statements to check which tile to spawn. Based on what a random number generator created, an if statement would determine whether to place a car, a log, or something else on the screen, making sure the game was always unpredictable.

I kept my code organized by putting things that were used often into functions with good, descriptive names. For example, the add_trauma() function is a simple way to increase the camera's shake, which is a great way to make the game feel more impactful.

⏳ Sandboy

A platformer game about controlling time made in Godot.

Bringing Complexity with Variables

The core of Sandboy is manipulating time, and I used variables to make this a central, dynamic mechanic. A variable called time_scale is what everything that moves in the game is multiplied by. This allows me to slow down or speed up all game elements at once. Using constants like SLOW_TIME, NORMAL_TIME, and FAST_TIME makes the code cleaner and easier to read, ensuring that the time values are consistent throughout the game. 

var time = 2
var time_scale: float = NORMAL_TIME
const SLOW_TIME: float = 0.5
const NORMAL_TIME: float = 0.85
const FAST_TIME: float = 1

Improving the Game with Logic (Conditionals)

I used conditional statements to determine how time should affect the player and the game world based on player input. The game checks which direction the player is moving, and if they are pressing the "walk left" or "walk right" buttons, it changes the time_scale accordingly. This allows the player to feel like they are directly controlling time. 

 if direction:
        velocity.x = direction * walkspeed * time_scale
        
        if Input.is_action_pressed("walk_L"):
            time = 1
            time_scale = SLOW_TIME
            set_vignette(slow_vignette, 0.28)
        elif Input.is_action_pressed("walk_R"):
            time = 3
            time_scale = FAST_TIME
            set_vignette(fast_vignette, 0.28)
            
        anims.play("move")
    else:
        time = 2
        time_scale = NORMAL_TIME
        velocity.x = move_toward(velocity.x, 0, walkspeed)
        anims.play("idle")
        set_vignette(null, 0)

Simplifying Code with Functions

Functions were essential for managing the complexity of the levels. For example, I created a function called spawn_solid_row() to automatically generate a row of solid blocks at certain points in the game. This provides the player with a short break from the moving platforms, and by putting this logic into a function, I avoided repeating the same code multiple times, making it much more efficient. 

func spawn_solid_row(y: float):
    var plat_width = 100 # Adjust this based on your solid platform's width
    var screen_width = get_viewport().size.x
    var num_platforms = ceil(screen_width / plat_width) + 1 # Spawn enough to cover the screen
    
    for i in range(int(num_platforms)):
        var plat = solid_platform_scene.instantiate()
        plat.position = Vector2(i * plat_width, y)
        add_child(plat)
        platforms.append(plat)
    
    trigger_screenshake(15.0, 0.3, 5.0) # Shake the screen to signal a new level

Streamlined Function: take_dmg()

The **take_dmg()** function centralizes all the logic for when an entity takes damage. This is highly effective because it prevents code repetition across multiple enemy and player scripts. It handles four key actions at once: **instantiating a damage label**, **updating the health value**, **applying a damage number**, and **updating the score** (with a difficulty bonus). This makes the code much cleaner and easier to read. 

func take_dmg() -> void:
    var damage_label = damageLabelScene.instantiate()
    damage_label.global_position = self.position
    damage_label.set_damage(damage)
    damage_label.z_index = 100
    health -= damage
    if (Global.diff == Global.Difficulty.PRO):
        Global.score += damage * 1.5
    else:
        Global.score += damage
